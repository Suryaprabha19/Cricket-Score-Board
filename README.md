# 🏏 Cricket Scoreboard in C

This is a simple console-based Cricket Scoreboard application written in C. It allows users to enter scores for two cricket teams over a set number of overs and determine the winning team at the end of the match.

## 🎯 Features

- Supports **two teams**.
- User can input:
  - Runs
  - Wickets
  - No Balls
- Automatically calculates and displays:
  - Total runs
  - Wickets
  - Overs (with ball precision)
- Declares the **winning team** or a tie at the end.

## 🛠️ How to Compile and Run

### ✅ Compile the program
```bash
gcc cricket_scoreboard.c -o scoreboard
./scoreboard
